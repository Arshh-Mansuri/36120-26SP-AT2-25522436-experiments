## Prediction targets

| Target | Type | Horizon | Definition |
|---|---|---|---|
| Climate Comfort Index (CCI) | Regression (0–100) | Next 3 days (t+1, t+2, t+3) | Weighted temperature, humidity, wind, cloud and rain comfort scores |
| Weather Hazard Category (WHC) | Multiclass classification | Exactly t+7 | Weather Hazard Index binned into Low / Moderate / High / Extreme Risk |

Only data before **2026-01-01** is used. Data from 2026 onwards is treated as production data.

## Setup

Requirements: [uv](https://docs.astral.sh/uv/) and Python 3.12 (uv installs it automatically).

```bash
# 1. Install dependencies (includes the custom package shiftguard from TestPyPI)
make requirements            # or: uv sync

# 2. Download Open-Meteo data (1980-2025, ~5 minutes) and build the processed dataset
make data                    # or: uv run python -m weather_experiments.dataset

# 3. Run the tests
make test                    # or: uv run pytest tests

# 4. Open the notebooks
uv run jupyter lab
```

The dataset step writes:

- `data/raw/hourly_by_year/` – one parquet file per year, cached so reruns are incremental
- `data/raw/sydney_hourly_1980_2025.parquet` – all hourly observations
- `data/processed/sydney_daily.parquet` – daily observations, same-day `cci`/`whi`/`whc` and the
  prediction targets `target_cci_t1..t3` and `target_whc_t7`

## Custom package

Reusable logic lives in the custom package **`shiftguard`** from AT1
([repo](https://github.com/Arshh-Mansuri/36120-26SP-group6-25522436-package),
[TestPyPI](https://test.pypi.org/project/shiftguard/)). Version 0.2.0 extends it with
`shiftguard.weather`: Open-Meteo retrieval, daily aggregation, target formulas, leakage-safe feature
engineering, chronological splits, baselines and metrics. The API repository uses the same package.
The original AT1 drift tools (`adversarial_auc`, `drift_report`, `TemporalGapSplit`) are used to
measure distribution shift between the training period and recent years.

```bash
pip install -i https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple shiftguard
```
